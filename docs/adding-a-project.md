# Add a Cybersecurity Project

## Create the Write-Up

1. Choose a short folder name such as `dns-traffic-analysis`.
2. Create `projects/dns-traffic-analysis/README.md` by copying the [project template](../templates/project-template.md).
3. Fill in the objective, lab environment, tools, and actual steps.
4. Mark the project **In progress** while evidence or analysis is incomplete.
5. Add screenshots to an `images/` folder within the project. Store sanitized supporting files in an `evidence/` folder.

## Link Evidence

For a screenshot stored in the project's images folder:

```markdown
![Description of the observation](images/observation.png)
```

For supporting evidence:

```markdown
[Sanitized event sample](evidence/event-sample.txt)
```

Explain the observation and why it matters in the surrounding text.

## Review Before Committing

- Check that every stated result is supported by actual work.
- Remove passwords, API keys, personal data, and confidential information.
- Check image paths and links in GitHub's Markdown preview.
- Record limitations and unsuccessful attempts where they affect the conclusions.
- Mark **Completed** only when the write-up and evidence are ready.
- Add the project link and status to the [homepage](../README.md) and [roadmap](../projects/README.md).

## Save the Changes

Use a descriptive commit message, such as `Add DNS traffic analysis findings`.

## Personalize the Homepage

Add your preferred name, learning interests, verified skills, and any contact link you choose to share. Only list certifications, employment, or completed projects that accurately describe your background.
